# Isolated node A Vulkan replay

Both builds use pinned llama.cpp 9d57ce456c94d241dde672b2db9cf18879766568 with the corrected Saker patch; the only source-code differences are the optional GDN epsilon patch in `src/models/models.h` and `src/models/qwen35.cpp`. Build and source hashes are in this directory. Production processes and files were not changed. The GPU was also in use by the existing GNOME compositor.

The same original request bytes were sent to both isolated loopback servers (request SHA256 d057e19bb773f5e783bcbda0813520ced8cba68c081fbfd4e79da9f498651db8). Its only semantic difference from the frozen CPU reference request is the server model alias. Both servers rendered exactly the same 367 token IDs as that reference. Each used the verified IQ3 model, ctx32768, b2048, ub256, 4 threads, FA on, MTP draft maximum 2, seed 42 and the frozen sampling settings.

- Baseline: one completed write_file call; 5539 completion tokens; generation 31.871 t/s; HTML SHA256 07be2bdea466290c920a2311dbeca981fd6199e42952ca6055b37db64d21aef4. Identical to the earlier node B output. Source and screenshot confirm spokes extend to radius 0.87 outside a tire of radius 0.48. QA also reports perpendicular scenery and frame-rate-dependent motion.
- Epsilon-patched: one completed write_file call; 6266 completion tokens; generation 30.753 t/s; HTML SHA256 d207d2cdbb5112767300d3081c271805e16e0d6e4efb1fdced3c7024de04e37b. Browser renders without JS errors. The generic checker reports spoke failure but this is a false positive: the tire outer radius is 0.5 and the centered spokes terminate at 0.5. A separate checker adapted to identify box-shaped road dashes recorded zero displacement under controlled mocked frame timing at both 30 and 60 fps; source calls `clock.getDelta()` repeatedly per object after `getElapsedTime()` and moves road dashes along Z while the bicycle wheel line is along X. The page is not a demonstrated successful repair.

These are single stochastic-seed samples with different generated outputs and lengths, not a controlled speed benchmark or proof that the patch causes a general quality improvement. Raw stream, response, unchanged HTML, screenshots, request, server logs, timing and loaded library hashes are retained per arm. QA instrumentation does not edit the generated HTML. The initial candidate bind to 18161 encountered TIME_WAIT and no listener; the second arm used 18162. All owned servers have exited; only the pre-existing compositor remained on the render node.

Full same-weight official HF-vs-float32-GGUF comparisons remain pending checkpoint completion. IQ3 versus official weights may reflect provenance and quantization differences, so no attribution to quantization alone is made.
